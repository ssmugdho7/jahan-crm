# Deployment Guide - Jahan CRM on Render

## Architecture
- **Runtime**: Docker (PHP 8.3 CLI + Node.js 20)
- **Database**: PostgreSQL (Render managed)
- **Frontend**: Vite (React + TypeScript + Tailwind)
- **Backend**: Laravel 12 + Inertia.js

## Prerequisites
- GitHub account with the repo `https://github.com/ssmugdho7/jahan-crm`
- Render account (https://render.com)

## Files Created for Deployment

### `Dockerfile`
Multi-stage Docker build:
1. **Stage 1 (frontend-builder)**: Node.js 20 Alpine - builds Vite assets
2. **Stage 2 (production)**: PHP 8.3 CLI - runs Laravel with all extensions

### `render.yaml`
Render Blueprint with:
- PostgreSQL database
- Docker-based web service
- Pre-deploy migrations
- All environment variables configured

## Steps to Deploy

### 1. Push Code to GitHub
```bash
cd C:\Users\user\Herd\crm
git add -A
git commit -m "Fix Render deployment with Docker + PostgreSQL"
git push origin main
```

### 2. Deploy on Render

#### Option A: Using Blueprint (Recommended)
1. Go to https://dashboard.render.com/blueprints
2. Click **New Blueprint**
3. Connect your GitHub repo: `ssmugdho7/jahan-crm`
4. Render will auto-detect `render.yaml` and create:
   - PostgreSQL database: `jahan-crm-db`
   - Web service: `jahan-crm`
5. Click **Apply** to start deployment

#### Option B: Manual Setup
1. Go to https://dashboard.render.com
2. Click **New +** → **Web Service**
3. Connect GitHub repo: `ssmugdho7/jahan-crm`
4. Configure:
   - **Name**: `jahan-crm`
   - **Runtime**: Docker
   - **Dockerfile Path**: `./Dockerfile`
   - **Pre-Deploy Command**: `php artisan migrate --force`
5. Add Environment Variables:

| Key | Value |
|-----|-------|
| APP_ENV | production |
| APP_DEBUG | false |
| APP_KEY | (Auto-generated) |
| APP_URL | https://jahan-crm.onrender.com |
| DB_CONNECTION | pgsql |
| DB_HOST | (From database) |
| DB_PORT | (From database) |
| DB_DATABASE | (From database) |
| DB_USERNAME | (From database) |
| DB_PASSWORD | (From database) |
| SESSION_DRIVER | database |
| CACHE_STORE | database |
| QUEUE_CONNECTION | database |
| LOG_CHANNEL | stack |
| LOG_LEVEL | error |

6. Click **Create Web Service**

### 3. Create Database
1. Go to https://dashboard.render.com
2. Click **New +** → **PostgreSQL**
3. Name: `jahan-crm-db`
4. Plan: Free
5. Click **Create Database**
6. Copy the **Internal Database URL** to use in web service env vars

### 4. Link Database to Web Service
1. Go to web service **Environment** tab
2. Add database env vars (or use render.yaml auto-linking):
   - `DB_HOST` → Database host
   - `DB_PORT` → Database port
   - `DB_DATABASE` → Database name
   - `DB_USERNAME` → Database user
   - `DB_PASSWORD` → Database password

## Environment Variables Reference

| Variable | Description | Source |
|----------|-------------|--------|
| APP_ENV | Application environment | Set to `production` |
| APP_DEBUG | Debug mode | Set to `false` |
| APP_KEY | Encryption key | Auto-generated by Render |
| APP_URL | Application URL | Set manually |
| DB_CONNECTION | Database driver | Set to `pgsql` |
| DB_HOST | Database host | From database service |
| DB_PORT | Database port | From database service |
| DB_DATABASE | Database name | From database service |
| DB_USERNAME | Database user | From database service |
| DB_PASSWORD | Database password | From database service |
| SESSION_DRIVER | Session storage | Set to `database` |
| CACHE_STORE | Cache storage | Set to `database` |
| QUEUE_CONNECTION | Queue driver | Set to `database` |
| LOG_CHANNEL | Log channel | Set to `stack` |
| LOG_LEVEL | Log verbosity | Set to `error` |

## Dockerfile Details

### Stage 1: Frontend Build
```dockerfile
FROM node:20-alpine AS frontend-builder
# Installs npm dependencies
# Runs npm run build (Vite)
# Outputs to /app/public/build
```

### Stage 2: Production
```dockerfile
FROM php:8.3-cli AS production
# Installs PHP extensions: pdo_pgsql, mbstring, gd, zip, redis
# Installs Composer
# Copies application code
# Copies built frontend from Stage 1
# Runs composer install --no-dev
```

## Build Process on Render

1. **Clone** repository
2. **Build Docker image** (multi-stage):
   - Build frontend assets (Node.js)
   - Install PHP dependencies (Composer)
3. **Pre-Deploy Command**: Run migrations
4. **Start**: `php artisan serve --host=0.0.0.0 --port=$PORT`

## Troubleshooting

### Build Fails
- Check Render logs for Docker build errors
- Ensure `Dockerfile` syntax is correct
- Verify all dependencies in `package.json` and `composer.json`

### Database Connection Issues
- Verify PostgreSQL is running on Render
- Check `DB_*` environment variables match database service
- Ensure `DB_CONNECTION=pgsql` (not sqlite)

### Assets Not Loading
- Frontend is built during Docker build stage
- Check if `public/build` directory exists in container
- Verify Vite build completed successfully

### Storage Link Issues
- Storage link is created during build
- If it fails, app still works (just no symlinked storage)

### Container Startup Issues
- Check if PHP extensions are properly installed
- Verify port binding (`--host=0.0.0.0`)
- Check `APP_KEY` is set
